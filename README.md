## Overview
This code was written for my final year project for finding pair states in Rb and Cs and characterising dipolar interactions for a given pair-state. The focus was finding states which would provide easy access to a F{\"o}rster resonance.

Core packages used:
- [pairinteraction](https://github.com/pairinteraction/pairinteraction)
- [Alkali Rydberg calculator (ARC)](https://github.com/nikolasibalic/ARC-Alkali-Rydberg-Calculator)
